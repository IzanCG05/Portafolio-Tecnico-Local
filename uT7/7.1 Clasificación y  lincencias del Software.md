1. Clasificación según su propósito
Software de sistema: gestiona el hardware y sirve de base al resto (Windows, GNU/Linux, controladores, UEFI/BIOS).
Software de programación: herramientas para crear, compilar, interpretar y depurar aplicaciones (VS Code, compiladores como gcc, intérpretes como Python y depuradores).
Software de aplicación: resuelve tareas concretas del usuario o empresa (ofimática, diseño/multimedia, navegadores, seguridad, ERP, ocio).
