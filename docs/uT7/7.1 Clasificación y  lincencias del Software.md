# 7.1. Clasificación y licencias del software

## 1. Clasificación del software según su propósito

El software es el conjunto de programas e instrucciones que permiten a un equipo informático funcionar y realizar diferentes tareas. Según su finalidad, podemos distinguir tres tipos principales:

| Tipo de software | Función | Ejemplos |
|---|---|---|
| Software de sistema | Gestiona el hardware y permite el funcionamiento del equipo. | Windows, GNU/Linux, controladores |
| Software de programación | Permite desarrollar, compilar y depurar programas. | Visual Studio Code, Python, GCC |
| Software de aplicación | Facilita la realización de tareas concretas al usuario. | LibreOffice, Photoshop, navegadores |

## 2. Licencias de software

Una licencia de software es un acuerdo legal que establece las condiciones bajo las que se puede utilizar un programa.

Sus principales funciones son:
- Definir los derechos de uso, copia, modificación y distribución.
- Proteger los derechos de autor.
- Establecer las condiciones legales de utilización.

Una licencia habitual en el software comercial es la **EULA** (End-User License Agreement), que establece las condiciones que acepta el usuario al instalar o utilizar un programa.

Es importante distinguir entre adquirir un programa y ser propietario de su código fuente: comprar una licencia normalmente concede un derecho de uso, no la propiedad del software.

## 3. Software libre y software gratuito

Aunque pueden parecer conceptos similares, no significan lo mismo:

- **Software libre:** permite utilizar, estudiar, modificar y distribuir el programa según las condiciones de su licencia. Puede ser gratuito o comercial
